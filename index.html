📖 使用教學 & 注意事項

📌 基本流程

  • 每個 SKU 可以設定多個 階段 (Phases)，每個階段有時間 + 相片網址
  • 時間到就會自動經 MMS 換相
  • Cron 每 15 分鐘 自動檢查一次

➕ 新增 SKU

  • 入 SKU ID（e.g. B0961005_S_4891609702053）
  • 🏬 Store ID：可選 — 唔同 store 嘅 SKU 填返自己間 store，留空用預設
  • 撳 🔍 取得名稱 自動拎產品名稱（可選）
  • 每個階段入：標籤 / 相片網址 / 時間
  • 撳 💾 儲存 SKU 儲存 → 自動跳去 SKU 列表

🖼️ 相片 URL

  • 要用 直接圖片連結（.jpg / .png / Google Drive CDN）
  • Google Drive: https://lh3.googleusercontent.com/d/{FILE_ID}
  • ❌ 唔好用 drive.google.com/file/d/...（HTML 頁面）

🗑️ 刪除

  • 單個刪除：撳 row 最右嘅 ✕ 掣
  • 批量刪除：剔選左邊 checkbox → 撳頂部「🗑️ 刪除已選」
  • 📝 Log 頁面同樣支援單個/批量刪除

⚠️ 注意事項

  • MMS session 大約 2-3 分鐘 過期，script 會自動 relogin
  • 相片 click 可以 放大預覽，再 click 關閉
  • SKU ID 係 clickable link → 直接去 HKTVmall product page
  • 如果 save 時出 SHA error 會 auto retry 5 次
  • Dashboard 每 30 秒 auto refresh

📊 Status 狀態

  • ⏳ 未開始 = 未開始
  • 🟢 進行中 = 進行中
  • 🔵 已完成 = 全部階段完成
  • ❌ 失敗 = 上載失敗
